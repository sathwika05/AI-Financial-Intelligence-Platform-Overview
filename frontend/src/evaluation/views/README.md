# frontend/src/evaluation/views

**Dashboard views.** One per screen of the benchmark dashboard.

| | |
|---|---|
| `SummaryView.tsx` | the run summary pictured in the root README |
| `RunsView.tsx / CompareView.tsx` | run history and arm-to-arm comparison |
| `PerQuestionView.tsx / GroupView.tsx` | per-question results and grouping |
| `MetricsView.tsx / TrendView.tsx / NodeLatency.tsx` | metrics, trends, per-stage latency |
| `RetrievalModesView.tsx / ProvidersView.tsx` | the retrieval and provider arms |
| `ValidationView.tsx / ErrorView.tsx` | ground-truth drift and error analysis |

_Implementations are private. This file lists what lives here and what it is responsible for._
